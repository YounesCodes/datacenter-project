# Instructions pour le dépôt

- Git Bash pour les opérations sur le dépôt. PowerShell pour les tâches natives Windows (services, registre, processus et ACL).
- Conserver le français pour les libellés, explications, erreurs et commandes visibles sur le site.
- Les dimensions de la maquette s’expriment en mètres et les prix en MAD. Actualiser le modèle dans `src/model.ts` et les règles de calcul dans `src/engineering.ts` avant de modifier des valeurs affichées.
- Conserver la provenance du repère géographique dans le modèle et le dossier de recherche. Le tracé cadastral nécessite des documents fonciers contrôlés.
- Lancer uniquement les tests pertinents pour le changement ou la fonctionnalité.
- Expliquer les changements, leur effet et les vérifications effectuées dans le compte rendu.
